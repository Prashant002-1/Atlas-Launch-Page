Security starts with saying what is true.

The public Atlas site is not a student-data product environment. A real pilot begins only after the data, provider, identity, retention, review, and incident boundaries are written down for that scope.

Public website

The access form is for launch requests. Do not submit student records, confidential course material, credentials, or sensitive personal information.

Product pilot

Course or student data requires a separate written scope, selected providers, operating controls, and terms before it enters Atlas.

What is in place on this site.

These statements describe the public website and access request path today. They do not imply controls for a future product deployment.

Browser boundaries

The site sends a restrictive content security policy, denies framing, limits browser permissions, and serves site assets from Atlas-controlled origins.

Access request validation

The form checks same-origin submissions, limits request size, validates required fields, filters accepted interest values, and uses a hidden spam field.

Request delivery

Form entries are delivered through Resend to the Atlas access inbox. The public form does not write submissions to a product database in this codebase.

Public-site providers

The site is hosted on Vercel and includes Vercel Web Analytics. The privacy page describes the information handled by the site and form.

Before student data enters a pilot.

The following are requirements to resolve with the institution. They are not presented as completed certifications or universal product settings.

Data map and purpose

Name every record Atlas receives, why it is needed, where it travels, and who can access it.

Identity and roles

Define teacher, student, assistant, and administrator access for the course and organization in scope.

Model providers and retention

Select the providers, contract terms, training use, storage behavior, deletion process, and retention period for that deployment.

Human review and incident response

Keep consequential course actions teacher-controlled and document escalation, correction, export, deletion, and incident ownership.

No borrowed badges.

Atlas does not claim SOC 2, ISO 27001, FERPA or COPPA compliance, zero data retention, or provider controls that have not been verified for the deployment in scope.
