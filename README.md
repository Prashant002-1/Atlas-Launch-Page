# Atlas Launch Page

A deliberately small, static placeholder for Atlas. It is isolated from the
Atlas-LMS application and contains no application code, runtime, API routes,
forms, analytics, environment variables, or secrets.

## Local preview

Run any static file server from this directory. For example:

```sh
python3 -m http.server 4173
```

## Removal

Delete the Vercel project from the Vercel dashboard, then delete this directory.
Neither action affects the Atlas-LMS repository.
